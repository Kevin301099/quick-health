# QuickHealth (website build)

QuickHealth is a healthy-food delivery concept: verified brands, lab-tested batches, quick delivery (15–30 min) and pan-India shipping.

This folder holds the **built static site** as published at https://claude.ai/artifact/FHxEn9GYxghceLANsZqcL6 (`index.html` is the landing page, `demo.html` the app demo, `qh-next/` the compiled Next.js assets). It is a compiled export; the original source project was built in another session and is not in this repository.

To view it locally, serve the folder with any static server, for example:

```bash
npx serve quickhealth-site
```
